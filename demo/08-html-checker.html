08 — HTML checker

Paste arbitrary markup and see it rendered twice, side by side at equal width: the left copy is pinned with translate="no"/.notranslate so it stays as the reference, the right copy is a normal candidate for the extension. Toggle the extension to simplify the right column only, then compare against the left in place — no scrolling between before/after. Both copies re-render (debounced) whenever the input changes.

Notes: <script> tags in the input do not execute (innerHTML never runs them), so paste content markup, not behaviour. Editing the input while the extension is ON replaces both columns' DOM — the MutationObserver then treats the right column as fresh content and simplifies it again, which also means "revert" no longer has the pre-edit text to restore. Toggle off before editing if you want a clean revert.
