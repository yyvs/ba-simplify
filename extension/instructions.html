Four things to know

  1. The backend does the rewriting, and it runs on your machine. No page text leaves your computer. Start it once with the three commands below — the panel above turns green when it is ready.
  2. Click the toolbar icon to simplify the page you are on. The text is replaced where it stands, so links, images and layout stay exactly as the author wrote them. A panel in the corner reports progress, what is doing the work, and how fast.
  3. Click the icon again to get the original text back. Nothing is saved to the page itself.
  4. You choose what rewrites the text. Press Simplifies with in the bar at the top of this page: a model, whether it reads sentence by sentence or whole sections at a time, and — for the prompted models — which audience it should write for. The same picker opens from a right-click on the toolbar icon, on any page.

Two things happen on their own: every run is written to History — the last 20 pages, with the text sent, what the model answered, and what the page ended up with — and if the backend is not running when you click the icon, a troubleshooting page opens with the steps to fix it.

Start the backend

  1. Open a terminal in the backend/ folder of the project.
  2. First time only — create the environment and install the dependencies: 
    python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
  3. Start the server, and leave it running: 
    ./run_dev.sh
    (or directly: uvicorn main:app --reload --port 8000)

Try it without leaving the extension

The demo pages are static test pages covering the cases that are awkward on a real site — bare interface labels, tables and forms, content that arrives late, and whole document sections. Nothing on them is loaded from the network.
